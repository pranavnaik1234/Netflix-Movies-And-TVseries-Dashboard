# Netflix Movies & TV Shows Analytics Dashboard

## Project Overview
This project analyzes Netflix movies and TV shows using Power BI.
The objective is to understand viewership, revenue, content type,
country performance, genres, languages, and director awards through
an interactive data analytics dashboard.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard KPIs
- Total Revenue: 648K
- Viewership Analysis
- Movie vs TV Show Analysis
- Director Awards

## Dashboard Analysis
The dashboard provides insights into:
- Viewership by Movie and TV Show
- Viewership by Country
- Revenue by Language
- Revenue by Genre
- Awards by Director
- Movie and TV Show performance
- Country-wise content analysis

## Dashboard Filters
Interactive filters are provided for:
- Country
- Genre
- Language
- Content Type

Users can also switch between Movie and TV Show using the
content-type filter.

## Key Business Questions
1. Which content type has higher viewership: Movies or TV Shows?
2. Which countries contribute the highest viewership?
3. Which language generates the highest revenue?
4. Which genres generate the most revenue?
5. Which directors have received the highest number of awards?
6. How does revenue vary across different languages and genres?
7. How does the performance of Movies compare with TV Shows?

## Project Workflow
1. Collected the Netflix movies and TV shows dataset.
2. Cleaned and transformed the data using Power Query.
3. Created required calculations and measures using DAX.
4. Analyzed revenue, viewership, genres, languages, countries,
   and awards.
5. Created interactive filters and visualizations.
6. Designed the final Power BI dashboard.
7. Extracted business insights from the dashboard.

## Key Insights
- Movies and TV Shows contribute differently to overall viewership.
- The United States is one of the major countries contributing to
  overall viewership.
- Revenue varies significantly across languages and genres.
- Action, Drama, Fantasy, Mystery, Sci-Fi, and Thriller genres
  contribute to the revenue analysis.
- Directors can be compared based on their total number of awards.
- Interactive filters make it possible to analyze specific countries,
  genres, languages, and content types.
